## ⚙️ 使用说明

### 1. 获取 DeepSeek API Key

访问 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册并创建一个 API Key。

### 2. 配置 .env 文件

将 `.env.example` 重命名为 `.env`，并填入你的 API Key：

示例：DEEPSEEK_API_KEY=sk-你的真实密钥

### 3. 运行游戏

双击 `魔女狼人杀.exe` 即可开始游戏。

> ⚠️ 提示：第一次启动可能需要等待几秒钟，AI 正在初始化。

---

## 📌 注意事项

- 运行需要网络连接（用于调用 DeepSeek API）。
- 首次运行请确保 `.env` 文件已正确配置。
- 游戏过程中请勿关闭命令行窗口（如有）。
- 游戏结束后，点击右下角「关闭游戏」按钮退出。

---

## 📖 项目简介

《魔女狼人杀》类似于**全自动的 AI 狼人杀模拟器**。六位性格迥异的小魔女将作为 AI 玩家，自主发言、投票、使用技能，展开一场充满推理与心理博弈的狼人杀对决。

你不需要做任何操作——打开程序，像观看一场戏剧一样，看着她们各自发挥自己的性格与智慧，在谎言与真相之间周旋。

---

## 🌟 游戏特色

- **14位拥有独立人格的AI小魔女**：每个人都有自己的说话风格、行为习惯和策略倾向。
- **全自动游戏流程**：从发牌、发言、投票到夜晚行动，全部由程序驱动。
- **完整狼人杀规则**：包含狼人、预言家、女巫、村民等角色，支持毒药、解药、查验、投票放逐等机制。
- **PyGame 可视化界面**：实时显示发言记录、玩家状态和当前发言者高亮。
- **历史发言自动滚动**：支持鼠标滚轮翻阅完整对话记录。
- **游戏结束后保持窗口**：可随时回顾所有角色的完整发言。
